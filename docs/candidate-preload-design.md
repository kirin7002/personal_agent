# 候选工具 Schema 预加载

日期：2026-11-14。

此文记录最初的控制候选预加载方案。当前实现已扩展为中文全局检索及关联查询预加载，见 [工具发现优化](tool-discovery-design.md)；下文旧版跳过规则和五入口描述不代表当前行为。

## 实现范围

Hermes 仍使用原来的五个目录协议工具。预加载只在任务创建时提供少量候选定义，不新增 S2S 工具，不增加一次路由模型调用，也不替模型生成参数。

链路：任务进入 → 本地召回 → 有充分候选则带上完整 Schema → Hermes 调用 `call_tools` → `finish_task`。必要时随时回到 `browse_capabilities` / `describe_tools`。

## 候选从哪里来

仅使用工具配置中的 title、aliases、description、examples 和稳定工具 ID。中文按字符二元/三元片段处理，英文按单词处理，用局部词频权重和相似度排序；特定标题短语与示例模板匹配提供额外信号。

检索时弱化阿拉伯/中文数字，防止把示例里的数值当作工具选择依据。原始用户指令不修改，参数始终由模型从原指令生成，并由原 Schema 校验。检索不会把45度改成30度。

索引按 `catalog_revision` 缓存，最多保留8个版本。预加载定义从当前任务固定的快照取出，不能混入后来导入的工具版本或已经停用的工具。

默认最多3个候选、12000个字符，最低分数0.70。分数是本地检索相似度，不是模型正确率或校准过的概率。

## 何时使用完整目录

- 出现组合、条件、查询等句式：保守跳过预加载。
- 候选置信度低、跨类别歧义、候选过多、Schema 超出预算：跳过预加载。
- 任务追问后的续接：不重新预加载，继续原任务上下文。
- 看似单句但语义上需要多工具的请求：Hermes 可以使用候选，再通过原目录补齐其他工具。
- 参数不足：照常追问；参数非法：照常拒绝或追问。
- 调用失败：保留结果与任务身份，继续原目录查证，不重新建立一个可能重复执行的任务。

句式判断是保守启发式，不是完整的意图分类器。因此候选始终只是提示，不作为工具权限、业务授权或“任务一定简单”的证明。

## 失败与成功仍需证据

参数校验、前置条件、幂等、任务轮次与取消检查均保持不变。`finish_task` 仍然必须引用有效结果，不会因为候选命中就自动报成功。

真实 Hermes 任务遇到业务控制失败时，如果目录里还有查询能力，不能只引用控制错误就结束；需要补充相关查询证据或向用户追问。参数/版本/模拟数据格式错误另按原修正流程处理。该约束同时用于关闭和开启预加载的两组对照，不只作用于优化组。

界面记录三类新轨迹：预加载候选、跳过预加载、继续完整目录查证。失败时原来的查询工具仍然全部可用，候选集合不限制后续调用范围。

## 配置与接口

环境变量：

| 配置 | 默认 | 作用 |
| --- | --- | --- |
| CANDIDATE_PRELOAD_ENABLED | true | 新任务默认是否开启 |
| CANDIDATE_PRELOAD_MAX_TOOLS | 3 | 候选上限，最大8 |
| CANDIDATE_PRELOAD_MAX_CHARS | 12000 | 候选定义字符预算，不是精确 token 数 |

`POST /api/tasks` 可显式传 `discovery_mode: "auto"` 或 `"off"`，用于同一服务版本的成对比较；未传时使用默认设置。模式会存入任务，追问接续保留原模式，同一个幂等键不能更换模式。

模型输入新增可选 `candidate_tools`，含目录版本和完整工具定义。业务 Schema 放在任务上下文，不放入系统提示。两组测试使用相同的通用系统提示，唯一差异是是否提供候选。

## 性能与正确性比较

固定用例见 `benchmarks/preload-cases.json`，覆盖数值不同于配置示例的简单指令、组合任务、语义组合、未配备/条件不满足、缺参追问和越界参数。

```sh
uv run python scripts/benchmark_preload.py --repeats 2
```

按顺序成对执行，交替 off/auto 先后顺序；每次建立独立任务和 Hermes 会话，不跨测试复用对话历史。两组使用同一模型、目录版本、模拟 profile 和目标指令。

主要指标为服务端任务创建到结果/追问的耗时、工具与参数正确性、目录调用次数、是否保留失败后的查询。追问用例的答案由脚本立即提供，不含人工思考时间。指标不包括 S2S 识别、VAD、音频播放与浏览器渲染，不能等同于完整语音体验延迟。

网络、模型推理和提示缓存存在波动；小样本结果用于本机方案比较，不是生产 SLA。正式比较结果另见性能报告。

对比时固定使用直连：本机 Hermes API 不经过环境代理，项目专用 Hermes 对指定百炼域名也使用直连。此前长运行测试遇到临时开发代理失效，正式统计不混入那次中断记录。
