## 已实现行为

| 功能 | 行为与证据 |
| --- | --- |
| 当前任务焦点 | 只由用户发起或明确交互更新；后台工具/周期进度不能抢焦点；终态不自动回退到更旧任务 |
| 取消短句 | “算了”“不用了”取消原任务；不重新启动模型；“别取消”“不用全部，主驾就好”不误取消 |
| 历史指代 | 描述或完整目标可定位过往任务；歧义时展示候选，用户选择可解除歧义；页面选择与文字冲突则确认 |
| 五分钟过期 | 当前问题进入等待后五分钟截止；事件重复和后台更新不续期；到期/回答原子校验；旧任务、旧通知不能恢复 |
| 文字和S2S一致 | 统一 conversation input；语音提交用户本轮原话，默认不猜 task_id，后端完成归属和状态检查 |
| 周期创建与修改 | 每日、每周、至少一分钟间隔；自然语言缺时间先追问；可查看、修改，使用运行环境当地时区 |
| 计划与执行分离 | 每次触发独立业务任务；同一计划+约定时间唯一；计划保留，单次结果可终结 |
| 上次未结束 | 包含等待回答/外部结果，跳过本次，不并行新开、不排队 |
| 暂停/恢复 | 暂停停止当前执行及未来触发；恢复只安排未来，不重启停止的执行，不补积压 |
| 取消范围 | 不明确时追问一次还是整个计划；取消一次保留之后周期；取消整个计划同时停止当前执行 |
| 错过触发 | 超过60秒调度宽限记为missed并通知，记录已知原因，不假装完成、不擅自补跑 |
| 有效通知 | 普通结果沿用任务发件箱，跳过/错过进入计划发件箱；修改后旧通知失效，不能清掉无关任务音频 |
| 等待成本 | 追问与等待通过本地结束本轮，不再向模型额外请求一次收尾；等待本身不调用模型 |

## 验证层次

1. 本地真实SQLite与受控时钟：覆盖五分钟边界、状态竞争、幂等、焦点、错误指代、跨会话隔离、周期领取/暂停竞争、夏令时、时间解析和计划版本。
2. 真实HTTP及VoiceBridge回调：同一业务实现，仅替换模型网络边界；验证输入和通知链路。
3. 真实Hermes：追问后继续原任务、取消、周期触发查询及不抢前台焦点。
4. 真实千问：用户原话经模型选择统一入口，返回音频。验证取消原任务及六轮计划管理。该部分采用文字输入/音频输出，未声称测试实体麦克风。
5. Chrome页面：测试当前焦点、过期、自然语言反馈、周期创建/编辑/暂停/恢复/范围取消及执行历史；另在已加载的本机服务做真实页面检查。

## 复查修复

- 否定管理语句先检查，不能把“不要取消整个计划”当作取消。
- 计划操作在等待远端停止前登记用户焦点，旧操作完成不得覆盖新焦点。
- 所有计划编辑都会处理旧到期事件后再计算下一次，防止旧事件用新目标执行。
- 多个时刻的表达先澄清，不能把第二个时间混进任务目标。
- 选中了明确的历史候选后，不再重复返回同一组歧义候选。
- 背景通知产生的模型响应不能再次派发任务；进入新用户轮次前结清已完成的通知，防止误关联。

## 边界

- 时间输入先支持明确的每日、每周和分钟间隔。复杂多时刻、每月等未支持规则会澄清，不伪装成已创建。
- 暂停、取消不会撤销已经生成的历史结果；现阶段没有真实车辆动作。
- 调度依赖本机服务运行，不提供本轮范围之外的生产高可用、开机启动或实体手机后台推送。
- 当前文字意图分流和时间解析是有边界的本地规则，不是任意语言理解保证；无法确定的输入应澄清。
