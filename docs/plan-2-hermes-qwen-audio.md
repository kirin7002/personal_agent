# 方案二：千问 Audio Realtime + Hermes 个人 Agent

日期：2026-11-13  
状态：调用预览与语音链路已完成真实联调；2026-11-14 增加分层能力目录，详见 `hierarchical-capability-catalog-design.md`。方案一单独保留。

## 当前开发范围（最新调整）

当前实现：用户指令 → Hermes 浏览车控/车书/车况目录 → 按需读取 Schema → 生成车控参数或读取模拟查询结果 → 校验并引用证据提交结论 → 通知 S2S。车控只做模拟下发成功；查询不会播报下发成功。所有业务数据均为 mock，不连接或控制真实车辆，不实现会变动的虚拟车辆。

用户已同意先采用明确标注、可替换的示例车控目录与 output schema。示例参数范围不代表任何真实车型的能力。根据用户确认，生成并校验成功即视为本次演示的下发成功，但输出始终保留 executed=false。

## 目标与结构

复用通用 Agent 的工具调用循环，让用户交代任务后，后台自主查询、执行，并在失败后补充证据、判断是否还能推进。

建议链路：S2S 或文字入口 → 会话与任务适配层 → Hermes → 车控、车书、本车配置与当前状态工具。

S2S 已选定阿里云百炼的千问 Audio Realtime 系列。具体 Plus / Flash 型号和快照版本尚未最终确定。Hermes 已作为后台 Agent 接入，并完成文本车控参数生成的真实联调；其后台模型固定为 deepseek-v4.1-flash-1017。

适配层连接前台会话与后台任务，负责任务关联、事件转发、用户补充信息与结果播报时机；复用 Hermes 的执行循环和任务接口，避免重新实现通用 Agent 内核。

## 已确认的设计决策

### D1：车辆任务统一交给 Hermes

所有车控、车书与车况请求均交给 Hermes。S2S 负责对话和派单，只暴露派发任务、补充信息、取消等少量任务入口，不直接注册大量车辆控制工具。

简单任务也经过 Hermes；失败后的查询继续在原后台任务中进行。接受简单操作多经过一层后台处理的代价。

### D2：普通插话不停止后台任务

用户插话或转聊其他内容时，后台任务默认继续。只有明确取消或修改原要求时，才调整任务。

打断播报与取消任务分开处理。取消后应停止后续可停止的步骤；已经产生的车辆操作不能宣称自动撤销。

### D3：结果在对话空闲时播报

用户正在说话或前台正在回复时，完成结果先等待当前轮次结束，再简短播报。当前空闲时直接通知。

忙闲判断、待播结果保存和去重由适配层负责。接口允许触发语音回复的阶段与实际用户播放状态都需要在联调中核实。

## 空气悬架示例

以下是后续完整执行方向；当前阶段只生成参数预览，不执行调节，也不宣称查证真实车辆配置。

用户要求调整空气悬架，S2S 派给 Hermes。Hermes 未找到控制接口时，继续查本车配置，必要时检索匹配车型版本的车书和当前车况。

最终区分：本车未配备、已配备但接口未接入、当前条件不满足、可以执行，以及证据不足。没有找到接口不等于车辆没有配置；车书介绍了选装功能也不等于本车已配备。

## 接入依据与待验证边界

- [Hermes Agent Loop](https://hermes-agent.nousresearch.com/docs/developer-guide/agent-loop)：已有模型调用、工具执行、结果回填与循环机制。
- [Hermes MCP](https://hermes-agent.nousresearch.com/docs/user-guide/features/mcp)：支持外部工具发现、注册与调用。
- [Hermes API Server](https://hermes-agent.nousresearch.com/docs/user-guide/features/api-server)：提供任务创建、进度、停止和追问接口。服务重启不等同于任务自动恢复。
- [千问 Audio 实时语音指南](https://help.aliyun.com/en/model-studio/qwen-audio-realtime-user-guides)：支持实时语音、工具调用和上下文管理。
- [千问 Audio 客户端事件](https://help.aliyun.com/en/model-studio/fun-audiochat-client-events)：支持对话项添加、工具结果回填及按轮次约束主动触发回复。

拟采用“派单立即返回已受理，任务完成后单独传递结果”的应用层设计。同一次工具调用不重复回填为受理和完成两个结果；后台通知不应被当成新的用户授权。

Hermes 后台已完成单项工具、多项工具与追问接续的真实验证。Qwen Audio 已完成固定语音输入、派单、参数生成和语音结果回传的真实验证；浏览器合成麦克风链路通过，插话门控另有自动测试，实体麦克风和复杂打断场景仍需设备实测。当前不实现虚拟车辆执行场景。

### D4：缺少必要信息时追问

已确认：缺少必要参数时由 S2S 代为追问，回答送回原 Hermes 任务继续处理，不自行猜测缺失的关键参数。

## 当前实现与后续验证
