在手机上连接助理

手机与电脑需连接同一局域网。首次语音连接需要手机信任这台电脑的本地 HTTPS 证书。

  1. 下载本机演示证书这是本机生成的测试证书，不是公开证书机构签发的证书。请只在你信任这台电脑时安装。
  2. iPhone：在“设置”中安装下载的描述文件，再到“通用 → 关于本机 → 证书信任设置”，为 Personal Agent Local Demo CA 开启信任。Android：按系统提示安装 CA 证书；不同设备菜单可能不同。
  3. 打开下方助理页面，输入电脑“连接手机”面板里的短时配对码。
打开手机助理

没有自动修改手机或电脑的证书信任设置。完成演示后可移除该证书。此页面只提供连接说明，不会分享模型凭据。
